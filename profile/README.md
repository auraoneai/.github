# AuraOne

AuraOne is a human data company for AI teams and a workflow service for enterprises. It supplies expert judgment, speech, physical-world data and checked workflows.

Website: https://auraone.ai
Company facts: https://auraone.ai/company/facts
Open tools: https://auraone.ai/open

## Open tools

All MIT licensed.

| Tool | What it does |
| --- | --- |
| [EvalKit](https://github.com/auraoneai/open) | Python CLI for rubric validation and linting, deterministic scoring, reviewer agreement, judge calibration, drift and leakage checks, and evidence reports. Runs on files you own. |
| [rubric-spec](https://github.com/auraoneai/rubric-spec) | Validate, lint, diff, and convert portable AuraOne Rubric Schema v1 files. |
| [iaa-kit](https://github.com/auraoneai/iaa-kit) | Measure inter-annotator agreement with modern metrics, uncertainty, ordinal support, and missing-data handling. |
| [judge-bench](https://github.com/auraoneai/judge-bench) | Probe judge behavior for position, verbosity, self-preference, paraphrase, anchoring, and calibration failures. |
| [lerobot-quality-gates](https://github.com/auraoneai/lerobot-quality-gates) | Check a LeRobot-style dataset's metadata, episodes, timestamps and video references before training or publication. |
| [Rubric Studio Open](https://github.com/auraoneai/rubric-studio-open) | Author, validate, preview, calibrate, diff, and export criterion-level AI evaluation rubrics. |
| [Agent Studio Open](https://github.com/auraoneai/agent-studio-open) | Connect agent systems, inspect tool traces, replay failures, compare candidates, and export regression evidence. |
